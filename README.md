📱 Quiz App

A simple and interactive Android Quiz Application developed using **Java** in **Android Studio**. The app presents users with multiple-choice questions. It's ideal for practicing general knowledge and testing your learning in a fun way.

## 🚀 Features

- 🧠 Multiple-choice quiz questions
- ✅ Instant answer validation
- 🔁 Option to restart the quiz
- 📱 Clean and user-friendly UI

## 🛠️ Built With

- Java
- Android Studio
- XML (for UI design)
